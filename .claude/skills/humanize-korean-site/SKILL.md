# 반도체 뉴스 트래커 문체 규칙 (im-not-ai 적용판)

규칙 원본은 [epoko77-ai/im-not-ai](https://github.com/epoko77-ai/im-not-ai)의 `humanize-korean` 스킬이다(MIT, `LICENSE-im-not-ai`).
`references/quick-rules.md`는 원본 v2.3.2(커밋 b37e020)의 룰북을 그대로 복사한 것이다. 이 파일만 고치지 말고 원본이 바뀌면 통째로 다시 복사한다.
릴리스 레이더(IROHA0508/release-radar)와 같은 규칙·같은 방식이다.

## 이 사이트에 맞춘 적용 범위

- **장르는 리포트(카드·기사 페이지)와 교재(이론 원고·애니메이션).** 목록·표·단계 목록은 의도된 구조다. C-2(불릿을 산문으로)와 E-1(장문 섞기)은 목록 항목에는 적용하지 않고 문단에만 적용한다.
- **존댓말(합쇼체) 유지.** "~합니다/~입니다"를 평어체로 바꾸지 않는다. 단계 제목·그림 글자처럼 원래 평어나 명사형인 곳은 그대로 둔다(register 보존).
- **절대 바꾸지 않는 것:** 수치, 단위, 날짜, 제품명·기술명(HBM4, SOCAMM2, 1c, EUV …), 회사·사람 이름, URL, 코드, 원문 직접 인용(따옴표 안), 한국어 기사의 원제, 영상·자료 제목(링크 글자). 서법도 그대로 둔다("~할 수 있다"를 단정으로 바꾸지 않는다).
- **제목:** 번역한 기사 제목과 기사 페이지 소제목의 "X: Y" 콜론 부제(C-10)는 하나의 명사구나 문장으로 합친다. 이론 원고의 단원 제목·절 제목과 애니메이션 단계 제목("ACT: …")은 교재의 실제 절 제목이라 원본 규칙대로 보존한다.
- **반도체 용어로 쓰는 '-적'은 F-5가 아니다:** 확률적 결함, 동적·정적 전력, 화학적·기계적 연마, 전기적 특성, 물리적 한계 등(`tools/style_check.py`의 `JEOK_NOUNS`).
- **원본이 기각한 신호는 보지 않는다:** A-2 "~를 통해", I-1 "~것이다", H-1 문두 접속사, J-2 따옴표, D-4 hype 어휘.

## 이 사이트에서 자주 걸리는 패턴 (2026-10-22 점검)

| ID | 무엇 | 처방 |
|---|---|---|
| C-11 | 연결어미(-고/-며/-지만/-면서/-아서/-어서) 뒤 쉼표 | 쉼표를 지운다. 새 쉼표를 만들지 않는다. 2,346개를 지웠고 테스트가 0건을 지킨다 |
| C-10 | 기사 제목·소제목마다 "X: Y" 콜론 부제 | 하나의 명사구나 문장으로 합친다 |
| C-8 | "A가 아니라 B" 대구가 한 문서에 2번 이상 | 하나만 두고 나머지는 평서문으로 |
| A-10 | 한 문서에 "~할 수 있습니다" 4번 이상 | 일부만 "~할 수도 있습니다", "~가 가능합니다" 등으로 분산(단정 금지) |
| F-5 | "~적 N" 추상 체인(전략적 협력, 안정적 공급 …) | 명사+명사나 풀어쓰기 |
| D-9·D-10 | "~로 이어집니다" 결산, "~하는 이유입니다" 도치 | 인과를 구체적으로 쓰거나 순방향 단언으로 |
| D-8 | "핵심은 ~", "중요한 것은 ~" 분열문 | 주어-서술로 바로 쓴다 |

## 쓰는 법

1. 글을 쓰거나 고친 뒤 `python3 tools/style_check.py --spans`로 신호를 확인한다(`--only theory`처럼 한 종류만 볼 수도 있다).
2. 연결어미 뒤 쉼표는 `python3 tools/style_check.py --fix-c11`이 지운다(따옴표·코드·링크 안과 명사 '참고,' '재고,'는 그대로).
3. 나머지는 걸린 문장만 손으로 고친다. 걸리지 않은 문장은 한 글자도 바꾸지 않는다(원본 철칙 '근거 기반').
4. 바뀐 글자 비율은 문장마다 30% 안으로 둔다. 원문 대비 수치·영문 표기·URL이 하나라도 달라졌으면 그 수정은 되돌린다.
5. 고친 곳에 맞춰 다시 만든다: 카드 → `python -m backend publish`, 원고 → `python tools/build_theory.py`, 애니메이션 목록 → `python tools/build_animation_index.py`. 그다음 `python -m backend validate`와 `python -m pytest tests -q`.

자동 요약(`backend/`)은 카드와 기사 페이지를 쓸 때 `references/quick-rules.md`를 프롬프트에 함께 넣고, 쓴 뒤 연결어미 쉼표를 지우고, 다른 신호가 남으면 걸린 문장만 Claude에게 한 번 더 다듬게 한다(`backend/humanize.py`). 수치·영문 표기·URL이 바뀌었거나 절반 넘게 바뀐 수정은 버리고 원래 문장을 둔다.

전체 파이프라인(진단 → 윤문 → 검증)이 필요하면 원본 플러그인을 설치해 쓴다.

```
/plugin marketplace add epoko77-ai/im-not-ai
/plugin install humanize-korean@im-not-ai
```
