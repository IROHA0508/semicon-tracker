# 이론 원고

반도체 면접 공부용 이론 원고입니다. 0층(입문)부터 6층(면접 실전)까지 7개 층, 59개 단원입니다. 2026-10-13에 claude.ai 문서(보관용)에서 이 폴더로 옮겼고, **이후 수정은 이 폴더에서만 합니다.**

```
theory/overview.md        개요와 학습 지도(읽는 법, 별표 기준, 전체 지도, 학습 경로, 반영한 자료)
theory/sources.md         출처(반영한 자료와 영상 출처)
theory/floors/<층>.md      층 제목과 한 줄 소개(0.md ~ 6.md)
theory/units/<단원>.md     단원 하나 = 파일 하나(0-1.md ~ 6-4.md, 59개)
theory/figures/*.svg      도식 80개(단원 79개 + 전체 지도 1개). 파일 이름 = <단원>-<순서>.svg
```

## 단원 파일 형식

```markdown
---
code: 4-5
tags: [HBM, HBM 적층(TSV·MR-MUF), 하이브리드 본딩]
---

# 4-5 HBM: TSV로 쌓은 D램과 MR-MUF·TC-NCF·하이브리드 본딩

면접 빈도 ★★★(SK하이닉스 면접 최빈출) · 이어지는 단원: 3-11 EDS(KGD), 3-12 패키징, …

**한 줄 정의** …
**비유** …
![그림 설명](../figures/4-5-1.svg)
**원리** …
**면접 단골 질문** …
**관련 뉴스 태그** `HBM4` `HBM3E` … — 최근 사례
**더 깊이** …
**영상으로 보기**
- [영상 제목](https://www.youtube.com/watch?v=…) — 채널 · 수준. 메모
**반영 자료** …
```

- 머리말(`---` 사이)에는 두 가지만 씁니다. `code`는 파일 이름과 같고, `tags`는 이 단원과 이어질 뉴스의 **표준 태그**(`data/tags.json`의 이름)입니다. 본문의 '관련 뉴스 태그'는 원고에 쓴 말 그대로이고, 표준 태그와 다를 수 있습니다(예: `HBM 테스트` → 테스트, HBM).
- 나머지는 본문에서 읽습니다. 제목은 첫 줄, 면접 빈도(별 개수)와 이어지는 단원은 둘째 줄, 그림은 `![…](../figures/…)`, 영상은 '영상으로 보기' 아래 `- [제목](주소) — 메모` 줄입니다. 영상을 찾지 못한 단원은 링크 없이 메모 한 줄을 둡니다.
- 6층 단원(공부 전략·질문 은행·답변 프레임·용어 사전)은 틀이 조금 다릅니다. 테스트는 공통으로 첫 줄, 면접 빈도 줄, '한 줄 정의', '관련 뉴스 태그', '반영 자료'만 확인합니다.

## 고친 뒤에 할 일

```
python tools/build_theory.py      # data/theory.json, data/units.json 다시 만들기
python -m pytest -q               # 원고 형식·링크·그림 점검 포함
```

- `data/theory.json`: 사이트가 읽는 단원 목록(층, 제목, 별, 이어지는 단원, 표준 태그, 그림, 영상, 애니메이션). 애니메이션은 `animations/catalog.json`에서 같은 단원 코드를 찾아 붙입니다.
- `data/units.json`: 기사 카드의 관련 단원을 고를 때 백엔드가 읽는 파일입니다. 직접 고치지 않고 이 도구로 만듭니다. 단원의 `tags`를 바꿨다면 이 파일의 `version`을 그날 날짜로 바꾸고 `python -m backend publish`로 기사 목록의 관련 단원도 다시 계산합니다.
- 두 파일이 원고와 어긋나면 테스트(`tests/test_theory.py`)가 실패합니다.

## 도식(SVG)

- claude.ai 문서의 도식 80개를 그대로 정적 SVG로 옮겼습니다. 글자·숫자·배치는 원래 도식과 같습니다. 개념도이며 눈금에 비례하지 않는 그림이 있습니다(그림 안에 적혀 있음).
- 색은 7가지 이름으로만 씁니다: `ink`(본문 글자), `quiet`(보조 글자), `edge`(선·화살표), `grid`(눈금선), `tint`(옅은 바탕), `acc`(강조, 구리색), `acc2`(두 번째 강조, 파란색). 요소에는 `class="f-ink"`(채우기), `class="s-edge"`(선)처럼 붙이고, 실제 색은 파일 맨 앞 `<style>`의 `--fig-*` 값이 정합니다. 애니메이션(`animations/player.css`)과 같은 계열의 색입니다.
- `<img>`로 넣으면 기기의 밝은·어두운 설정을 따릅니다. 페이지에 직접 넣으면(inline) `<html data-theme="dark">`·`"light"`도 따릅니다.
- 새 그림을 그리거나 다시 그릴 때도 같은 색 이름과 `class="fig"` 바깥 틀을 쓰고, 외부 파일·글꼴을 불러오지 않습니다(테스트가 확인).
