# 6-3 답변 프레임: 현상 → 원리 → 시사점, 그리고 PT 실전 사례

면접 빈도 — (실전 연습용, PT 면접 대비) · 이어지는 단원: 3층 전체, 3-13, 6-2

**한 줄 정의** 좋은 답변은 내용보다 순서에서 먼저 갈립니다. 지식 질문은 '결론 → 원리 → 근거 → 연결', 불량·PT 질문은 '현상 정의 → 원인 후보 → 데이터로 좁히기 → 대책과 재발 방지', 산업 질문은 '사실 → 해석 → 영향 → 나의 역할' 순서로 답하면 짧고 논리적으로 들립니다.

**비유** 의사의 진료와 같습니다. 증상을 확인하고(현상), 가능한 병을 떠올리고(원인 후보), 검사로 좁힌 뒤(데이터), 처방하고 재발을 막습니다(대책).

![세 가지 답변 프레임(지식형·불량 PT형·산업형)](../figures/6-3-1.svg)

세 줄은 각각 지식형, 불량·PT형, 산업형 질문의 답변 순서입니다.

**프레임 사용 예**

- 지식형: 'CMP가 왜 필요한가요?' → ① 미세 공정에서 표면 단차를 없애 다음 공정의 마진을 확보하기 위해서입니다. ② 프레스톤 식처럼 튀어나온 곳이 더 빨리 깎여 평탄해집니다. ③ 단차가 있으면 포토의 초점 여유(DOF)를 벗어나고 식각에서 잔여물·단락이 생깁니다. ④ 하이브리드 본딩처럼 나노미터 평탄도가 필요한 HBM 공정에서 더 중요해집니다(3-10).
- 산업형: 'HBM 시장을 어떻게 보나요?' → ① 2026년 2분기 점유율은 SK하이닉스 50%, 삼성전자 33%(카운터포인트)입니다. ② 기술 선점 효과가 크다는 시각과 경쟁사 추격으로 격차가 줄 수 있다는 시각이 함께 있습니다. ③ 장기 계약과 커스텀 HBM이 늘어 고객 협업 역량이 중요해졌습니다. ④ 저는 패키징 직무에서 적층 수율과 열 관리 개선에 기여하고 싶습니다.

**불량·PT 실전 사례(합격자 PDF 24쪽 PT 주제 정리)**

**사례 1. ADI CD 불량(HBM 게이트)** 문제: 게이트의 현상 후 CD(ADI) 스펙이 30 ± 3 nm인데 포토의 노광 시간 마진이 부족해 CD가 스펙을 벗어나고 재작업률이 50%까지 올랐습니다(DUV, 반사 방지막 SiON 200 Å 조건).

1. 설계: 더미 패턴을 넣어 노광·현상·식각의 균일성을 확보하고 OPC로 마스크 패턴을 보정합니다.
2. 포토: 노광 시간 최적화, 이머전용 감광막, SADP, 장기적으로 EUV 전환을 검토합니다.
3. 식각: 식각 바이어스를 조절해 CD를 보정하고 선택비를 확보합니다.
4. 증착: 반사 방지막(ARC) 두께와 균일도를 최적화해 반사를 제어합니다.
5. 마무리 한 문장: 한 공정만이 아니라 앞뒤 공정까지 함께 보겠다는 관점을 보여 줍니다.

**사례 2. 양성 감광막(+PR) 라인 CD 불량** 문제: 노광 후 감광막 라인의 CD가 커지거나 산포가 커졌습니다.

1. CD가 커질 때: 감광막이 두꺼움(점도↑, 회전수↓, 온도↓), 감도 저하(유효기간 경과, 소프트 베이크 부족, 용매 잔류), 노광량 부족과 PEB 온도·시간 부족, 현상 부족(현상액 농도·온도·시간↓), 과도한 하드 베이크로 감광막이 흘러내림.
2. 산포가 커질 때: 도포 두께 불균일(회전·진동), 소프트 베이크 온도 불균일, 노광 세기 불균일이나 장비 오류.

**사례 3. SPC로 본 CMP 가장자리 링 불량(IMD-1)** 문제: 수율이 떨어진 구간에서 웨이퍼 가장자리에 링 모양 불량이 보이고 IMD-1 CMP 뒤 두께 데이터에서 장비별 차이가 보입니다.

1. SPC: 측정값의 평균·표준편차와 Ppk를 계산해 어느 장비·구간이 관리를 벗어났는지 확인합니다(3-13).
2. 원인 후보: 슬러리 공급 불균일과 패드 마모, 헤드의 압력 분포 불균일, 웨이퍼 장착 편차.
3. 개선: 가장자리 구역(zone) 압력을 조정해 과연마를 줄이고 슬러리 공급 유량을 맞추고 컨디셔너 교체·세정 주기를 줄이고 헤드 압력과 플래튼 속도를 보정해 균일도를 높입니다.

**사례 4. ICP-RIE 식각률 맵** 문제: 5인치 웨이퍼를 식각한 뒤 식각률 맵을 보니 (a) 가장자리가 낮거나 (b) 한쪽이 낮습니다.

1. 가장자리 식각률 저하: 원인은 플라즈마 밀도의 중앙 집중, 가스 분포, 척 온도. 대책은 샤워헤드 홀 패턴과 가장자리 유량 보정, RF 파워 분포 균일화, 척 히터 구역 조정입니다.
2. 한쪽 식각률 저하: 원인은 배기구 위치 치우침, 챔버 내부 온도 편차, 플라즈마 비대칭. 대책은 가스 유입·배기 라인 점검, 온도 센서·히터 점검, 전극 평행도 보정입니다. 맵의 모양(중심 대칭인지, 한쪽 치우침인지)이 원인을 고르는 첫 단서입니다.

**사례 5. 고종횡비(HAR) 식각 프로파일 차이** 문제: 큰 패턴은 정상인데 작은 패턴은 마스크가 먼저 닳고 식각이 멈춥니다.

1. 원인: 미세 패턴일수록 반응물이 바닥까지 들어가고 부산물이 빠져나오기 어려운 로딩 효과(종횡비 의존 식각, ARDE).
2. 대책: ICP의 소스·바이어스 파워 조절, 더미 패턴으로 밀도 균일화, 원자층 식각(ALE), 펄스 플라즈마(꺼진 동안 부산물 배출).
3. 연결: 고종횡비 구조는 증착(HDP·ALD로 빈틈 채우기), CMP(밀집부 이로전), 포토(해상도 확보)까지 함께 어려워진다는 점을 덧붙이면 좋습니다.

**사례 6. 배선 단면 읽기(Al 대 Cu)** Cu 배선은 비아와 금속이 같은 재료로 이어져 보이고(듀얼 다마신), 절연막에 판 홈을 채워 위가 넓은 역사다리꼴이 됩니다. 그래서 빈틈 채우기와 단면적 감소를 주의해야 합니다. Al 배선은 비아(W 플러그)와 금속이 다른 재료라 구분되어 보이고 금속을 깎아 만들어 아래가 넓은 사다리꼴이 됩니다. 완전히 수직으로 깎기 어렵기 때문입니다(3-9).

**사례 7. 배치형 ALD 장비의 특정 슬롯 불량** 문제: 한 번에 여러 장을 처리하는 ALD 장비에서 4·8·12·16번 슬롯 웨이퍼만 두께가 벗어납니다.

1. 현상: 일정 간격으로 반복되므로 규칙성이 있는 시스템 불량으로 봅니다.
2. 원인 좁히기: lot 이력과 슬롯 배치 기록을 맞춰 보고, 해당 위치의 히터, 가스 분사, 배기, 웨이퍼 홀더(보트), 이송 로봇을 점검합니다.
3. 대책과 재발 방지: 정비(PM)로 부품을 교체·보정하고 슬롯별 모니터 웨이퍼와 FDC 알람, 이상 시 자동 hold를 걸어 둡니다.

**식각 변수 정리(합격자 필기의 '공정 데이터')**

| 변수 | 올리면 | 내리면 |
| --- | --- | --- |
| 압력 | 충돌이 늘어 라디칼 반응·등방성↑ | 평균 자유 행로↑, 이온 직진성↑(이방성) |
| 소스 파워(RF) | 이온화·플라즈마 밀도↑, 식각 속도↑ | 밀도↓ |
| 바이어스 파워 | 이온 충돌 에너지↑, 식각 속도·이방성↑, 표면 손상↑, 선택비↓ | 손상↓, 선택비↑ |
| 척 온도 | 화학 반응↑, 식각 속도↑ | 감광막 손상↓, 선택비↑(극저온 식각) |
| 가스 유량 | 압력↑, 체류 시간↓ | 반응물 공급 부족 |
| 가스 종류 | F 계열(CF₄·CHF₃)은 산화막 식각, C/F 비가 높으면 측벽 보호 폴리머↑ | Cl 계열(Cl₂·BCl₃)은 금속·실리콘 식각 |

**면접 단골 질문**

- Q. (PT) 식각 후 웨이퍼 맵이 이렇게 나왔습니다. 원인과 대책은? → 맵 모양으로 원인 계열 고르기 → 데이터 확인 항목 → 대책 → 검증.
- Q. 공정 조건을 바꿨더니 다른 문제가 생겼다면? → 부작용(side effect)까지 확인하는 검증 절차와 앞뒤 공정 영향.
- Q. 데이터가 부족할 때는 어떻게 원인을 찾나요? → 실험 설계(DOE)와 비제품 웨이퍼(NPW) 평가, 단면 분석(SEM·TEM).
