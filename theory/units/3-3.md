# 3-3 산화: 건식·습식 산화와 게이트 절연막

면접 빈도 ★★★ · 이어지는 단원: 2-2 MOSFET, 2-3 MOSFET 특성(C-V), 3-8 이온주입·열처리, 3-9 금속배선(HKMG)

**한 줄 정의** 산화는 실리콘 웨이퍼를 고온에서 산소나 수증기와 반응시켜 표면에 SiO₂ 막을 키우는 공정으로, 계면 결함이 적은 고품질 절연막을 정밀한 두께로 만들 수 있습니다.

**비유** 깎아 둔 사과 표면이 공기에 닿아 갈색으로 변하듯, 실리콘도 산소를 만나면 표면이 산화막으로 변합니다. 반도체는 이 '갈변'을 온도와 시간으로 정밀하게 조절해 보호막과 절연막으로 씁니다. 표면에 덧칠하지 않고 사과 속살(실리콘)을 먹어 들어가며 자란다는 점도 같습니다.

![산화막 성장 모습(왼쪽), 건식·습식 산화의 두께 곡선(가운데, 개념도), 산화막의 쓰임(오른쪽)](../figures/3-3-1.svg)

왼쪽은 산화막이 원래 표면(점선)의 위아래로 자라는 모습, 가운데는 건식과 습식 산화의 속도 차이, 오른쪽은 산화막의 네 가지 쓰임입니다.

**원리**

1. 반응식: 건식은 Si + O₂ → SiO₂, 습식은 Si + 2H₂O → SiO₂ + 2H₂입니다. 산화제가 이미 생긴 산화막을 뚫고 확산해 Si/SiO₂ 계면에서 반응하므로 막은 실리콘 쪽으로 자랍니다. 산화막 두께의 약 44%만큼 실리콘이 소모됩니다.
2. 성장 속도(딜-그로브 모델): 얼을 때는 계면 반응 속도가 결정해 두께가 시간에 비례(선형)하고 두꺼워지면 산화제가 막을 통과하는 확산이 느려져 두께가 시간의 제곱근에 비례(포물선)합니다.
3. 속도에 영향을 주는 요인: ① 산화 방식(습식이 훨씬 빠름) ② 온도와 챔버 압력이 높을수록 빠름 ③ 불순물이 많이 주입된 영역은 빠름. 여기에 결정면도 영향을 주어 (111) 면이 (100) 면보다 빠릅니다.
4. 산화막의 4가지 용도: ① 표면 보호(소자 특성에 가장 큰 영향을 주는 실리콘 표면을 긁힘·먼지로부터 보호) ② 소자 분리(인접 소자를 물리·전기적으로 절연) ③ 이온주입의 블로킹 마스크·버퍼층·하드마스크 ④ 게이트 절연막.
5. 막 품질: 계면의 댕글링 본드(끊어진 결합)가 적을수록 좋은 막입니다. 열산화막은 천천히 자라 이 결함이 적고 산화 뒤 수소 분위기 열처리로 남은 결합을 막아(패시베이션) 계면 트랩을 더 줄입니다.
6. LOCOS에서 STI로: 예전에는 질화막으로 덮지 않은 곳만 두껍게 산화해 소자를 분리(LOCOS)했지만 산화막이 옆으로 번지는 버즈빅 때문에 미세화에 불리해, 트렌치를 파고 절연막을 채우는 STI로 바뀌었습니다(2-4, 3-14).

**건식 산화와 습식 산화**

| 구분 | 건식 산화 | 습식 산화 |
| --- | --- | --- |
| 산화제 | O₂ 기체 | H₂O(수증기) |
| 속도 | 느림 | 빠름 |
| 막질 | 치밀하고 계면 특성 우수 | 상대적으로 덜 치밀 |
| 두께 제어 | 정밀 | 두꺼운 막에 유리 |
| 쓰임 | 게이트 산화막(GOX), STI 라이너, 패드 산화막 | 필드 산화막, 세정용 희생 산화막 |

**산화막과 도핑을 평가하는 방법**

| 무엇을 | 방법 | 원리와 특징 |
| --- | --- | --- |
| 두께(대략) | 커러 차트 | 두께에 따라 반사색이 달라짐, 오차가 큼 |
| 두께(정밀) | 간섭식 두께 측정기 | 공기/SiO₂, SiO₂/Si 계면에서 반사된 빛의 간섭 |
| 두께·굴절률 | 엘립소미터 | 반사광의 편광 상태 변화 |
| 단면 두께 | FIB 단면 + SEM | 이온빔으로 잘라 직접 관찰 |
| 파티클 | 레이저 산란 검사 | 파티클에 산란된 빛을 검출(패턴 없는 웨이퍼) |
| 도핑 농도 | 4-포인트 프로브 | 면저항 측정, 활성화된 도펀트만 반영 |
| 깊이별 도핑 | SRP | 비스듬히 연마한 뒤 두 프로브로 깊이별 저항 측정 |
| 깊이별 도핑 | SIMS | 이온으로 표면을 깎아 튀어나온 2차 이온을 분석, 비활성 불순물까지 측정 |
| 전기적 품질 | C-V 곡선 | 축적 영역의 최대 용량(Cox)으로 두께·유전율, 평탄대 전압 이동으로 산화막 속 고정 전하 |
| 신뢰성 | TZDB, TDDB | 전압을 올려 즉시 파괴되는 전압 / 일정 전기장에서 파괴되기까지 걸리는 시간 |

**면접 단골 질문**

- Q. 반도체에서 산화막은 어디에 쓰나요? → 표면 보호, 소자 분리, 이온주입 마스크·버퍼, 게이트 절연막.
- Q. 건식과 습식 산화의 차이와 쓰임은? → 산화제, 속도, 막질의 차이를 말하고 얼고 정밀한 게이트 산화막은 건식, 두꺼운 필드 산화막은 습식으로 연결합니다.
- Q. Gate Oxide, IMD, ILD 중 가장 중요한 산화막은? → 게이트 산화막. 단순 절연막이 아니라 채널과 게이트 사이에서 문턱전압, 게이트 누설, 서브스레숄드 특성, 이동도, 신뢰성을 직접 결정하기 때문입니다. 계면이 나쁘면 계면 트랩이 늘어 이동도가 떨어지고 편차와 열화가 커집니다. IMD·ILD도 배선 절연과 RC 지연에 중요하지만 주로 배선 성능에 영향을 주므로 우선순위가 낮다고 답합니다.
- Q. 산화막 두께는 어떻게 측정하나요? → 커러 차트(간이), 간섭식 측정기·엘립소미터(비파괴, 정밀), FIB-SEM 단면(파괴).
- Q. 4-포인트 프로브와 SIMS의 차이는? → 4-포인트는 전기적 측정이라 활성화된 도펀트만 보고, SIMS는 질량 분석이라 활성·비활성 불순물을 모두 깊이별로 봅니다.

**관련 뉴스 태그** `게이트 산화막` `High-k` `퍼니스 장비`

**더 깊이** 게이트 산화막이 1\~2 nm 수준까지 얇아지자 터널링 누설 때문에 SiO₂만으로는 한계에 부딪혔고 하프늄 산화물(HfO₂) 같은 High-k 절연막과 금속 게이트(HKMG)로 넘어갔습니다(3-9).
