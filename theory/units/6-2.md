# 6-2 단골 질문 은행: 질문 → 단원 연결

면접 빈도 — (실전 연습용) · 이어지는 단원: 전체, 6-3 답변 프레임

**한 줄 정의** 면접 질문은 원리형·비교형·문제해결형·산업형·경험형 다섯 유형으로 나뉘고 대부분은 이 원고의 어느 단원에서 답의 재료를 찾을 수 있습니다. 질문을 보자마자 '어느 단원, 어느 그림'이 떠오르게 만드는 것이 목표입니다.

**비유** 시험 직전의 오답 노트입니다. 문제를 다시 푸는 대신, 어느 개념에서 나온 문제인지 바로 찾아가는 색인을 만드는 것입니다.

![면접 질문의 다섯 유형과 답하는 틀](../figures/6-2-1.svg)

질문 유형을 먼저 알아차리면, 6-3의 어느 답변 틀을 꺼낼지가 자동으로 정해집니다.

**연습하는 방법**

1. 표에서 질문 하나를 고르고 30초 안에 첫 문장(결론)을 소리 내어 말합니다.
2. 해당 단원의 그림을 종이에 그리면서 1분 동안 설명합니다.
3. '왜요?'라는 꼬리 질문을 스스로 두 번 던지고 답해 봅니다. 막히는 곳이 다음에 공부할 곳입니다.
4. 산업 질문은 면접 전날 뉴스 트래커로 숫자를 최신으로 바꿉니다.

**모르는 질문을 받았을 때** '정확히는 모르지만, ○○ 원리로 보면 △△일 것 같습니다'처럼 아는 원리에서 출발해 추론 과정을 보여 줍니다. 아는 척 단정하는 것보다 훨씬 좋은 인상을 줍니다.

**관련 뉴스 태그** `면접` `기출`
