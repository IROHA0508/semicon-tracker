# 0-2 칩의 일생

면접 빈도 ★★★ · 이어지는 단원: 3-0 팹 입문, 3-14 CMOS 전체 공정 흐름

**한 줄 정의** 칩은 설계 → 포토마스크 → 웨이퍼 → 전공정 → 테스트 → 패키징 순서로 만들어지며 웨이퍼가 팹에 들어가서 나오기까지만 2\~3개월, 800개가 넘는 공정 단계를 거칩니다.

**비유** 아파트 짓기와 같습니다. 설계도(회로 설계)를 그리고 도면을 판화 틀(포토마스크)로 만든 뒤, 땅(웨이퍼) 위에 층층이 짓고(전공정), 준공 검사(EDS)를 받고 입주 준비(패키징)를 마칩니다.

![칩의 일생 · 설계에서 출하까지 8단계](../figures/0-2-1.svg)

윗줄은 회로를 새기는 앞단, 아랫줄은 칩을 골라 포장하는 뒷단입니다. 전공정은 한 번이 아니라 층마다 같은 공정을 되풀이합니다.

**단계별 설명**

1. 설계: 칩의 기능을 정하고 회로를 하드웨어 기술 언어(Verilog 같은 HDL)로 작성합니다. 이를 트랜지스터와 배선의 배치도(레이아웃)로 바꿉니다.
2. 포토마스크: 레이아웃을 층별로 나눠 고순도 석영 유리판에 새깁니다. 칩 하나에 수십 장이 한 세트입니다.
3. 웨이퍼 제조: 모래에서 얻은 초고순도 실리콘을 원기둥(잉곳)으로 키우고 얇게 잘라 매끄럽게 갈아 원판을 만듭니다(3-1).
4. 전공정: 산화, 포토, 식각, 증착, 이온주입, 금속배선을 층마다 반복합니다. 트랜지스터를 만드는 아래쪽 부분을 FEOL, 그 위를 배선으로 잇는 부분을 BEOL이라고 합니다.
5. EDS: 웨이퍼 상태에서 칩마다 전기 신호를 넣어 양품과 불량을 고르고 고칠 수 있는 칩은 수선합니다(3-11).
6. 패키징: 웨이퍼를 칩 단위로 자르고 기판에 붙여 전기를 잇고 수지로 감쌉니다(3-12).
7. 최종 테스트: 고온·저온과 실제 속도에서 동작을 확인해 등급을 나눌 뒤 출하합니다.

**8대 공정, 두 가지 분류법** 면접에서 자주 헷갈리는 부분입니다.

- 삼성전자식 8대 공정: 웨이퍼 제조, 산화, 포토, 식각, 증착·이온주입, 금속배선, EDS, 패키징. 칩의 일생 전체를 8단계로 나눈 것입니다.
- 공정기술 직무식 전공정 분류(합격자 노트): 세정, 산화·확산, 포토, 식각, 박막 증착, 이온주입, 금속배선, CMP. 팹 안의 전공정만 더 잘게 나눈 것입니다.
- 지원 직무가 공정기술이면 두 번째 분류로, 그 외 직무면 첫 번째 분류로 말하면 자연스럽습니다.

**알아 둘 숫자와 용어**

| 용어 | 뜻 |
| --- | --- |
| TAT(Turn-Around Time) | 웨이퍼가 공정을 모두 도는 데 걸리는 시간. 팹에서만 2\~3개월 |
| Lot(로트) | 함께 움직이는 웨이퍼 묶음. 보통 25장 |
| Run sheet(traveler) | 로트마다 따라다니는 작업지시서 |
| FEOL / BEOL | 트랜지스터를 만드는 앞부분 / 배선을 쌓는 뒷부분 |

**면접 단골 질문**

- Q. 반도체가 만들어지는 과정을 설명해 보세요. → 뼈대: 설계 → 마스크 → 웨이퍼 → 전공정 반복 → EDS → 패키징 → 최종 테스트. 마지막에 지원 공정 하나를 한 단계 더 깊게 설명하면 좋습니다.
- Q. 전공정과 후공정의 차이는? → 전공정은 웨이퍼 위에 회로를 새기는 단계, 후공정은 칩을 검사하고 자르고 포장하는 단계입니다. HBM처럼 패키징이 성능을 좌우하면서 두 경계가 흐려지고 있다는 한마디를 덧붙이면 좋습니다.

**관련 뉴스 태그** `팹 투자` `패키징` `HBM` — 예: SK하이닉스는 2026년 8월 용인 Y2·청주 M17 팹에 54조 원 투자를 발표했습니다([SK hynix Newsroom](https://news.skhynix.com/en/fab-facility-investment-2026/)).

**더 깊이** 전공정 단계의 약 1/3은 세정입니다. 공정을 많이 거칠수록 오염이 쌓이기 때문입니다(3-2). 또 공정 단계가 많을수록 각 단계의 작은 불량이 곱해져 수율이 떨어집니다(3-13).
