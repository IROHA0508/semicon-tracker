# 3-4 포토: 노광 공정 순서와 해상도

면접 빈도 ★★★(직무 공통 최다 빈출) · 이어지는 단원: 3-6 식각, 3-13 계측, 4-2 EUV·High-NA

**한 줄 정의** 포토(리소그래피)는 감광액(PR)을 바른 웨이퍼에 마스크를 통해 빛을 쬐어 회로 무늬를 옮기는 공정으로, 얼마나 작게(해상도) 얼마나 정확히 겹쳐(오버레이) 그릴 수 있는지가 미세화의 한계를 정합니다.

**비유** 필름 사진 인화입니다. 인화지(PR)에 필름(마스크)을 대고 빛을 비춘 뒤 현상액에 담그면 그림이 나타납니다. 작은 글씨를 선명하게 찍으려면 더 날카로운 빛(짧은 파장)과 더 큰 렌즈(높은 NA)가 필요합니다.

![포토 공정 8단계의 단면 변화(파랑 = PR, 주황 줄 = 식각할 막, 아래 띠 = 핫플레이트)](../figures/3-4-1.svg)

여덟 칸이 웨이퍼가 거치는 순서입니다. 노광은 스캐너에서, 나머지는 트랙(코터·디벨로퍼) 장비에서 진행됩니다.

**공정 순서 자세히**

1. 전처리: 세정 후 베이크로 표면 수분을 날리고 HMDS를 발라 PR이 잘 붙게 합니다. 필요하면 아래쪽 난반사를 막는 BARC(반사 방지막)를 먼저 코팅합니다.
2. PR 스핀 코팅: PR을 떨어뜨리고 빠르게 돌려 고르게 폅니다. 두께는 PR의 점도, 회전 속도(RPM), 웨이퍼 크기로 정해집니다. 가장자리에 PR이 두껍게 뭉치는 엣지 비드는 용매를 뿌리거나 가장자리만 노광해 없앱니다(EBR). PR과 하부막의 접착이 나쁘면 패턴이 들뜨는 리프팅 불량이 납니다.
3. 소프트 베이크: 액체 상태로 바른 PR 속 용매를 날려 PR을 굳히고 하부막과의 접착을 높입니다. 생략하면 리프팅이 생깁니다.
4. 정렬·노광: 마스크를 아래층 패턴에 맞춰 정렬(오버레이)한 뒤 빛을 쬡니다. 노광 방식은 접촉식(마스크 손상) → 근접식(약 50 μm 띄움, 회절로 해상도 저하) → 투영식(렌즈로 축소 투영, 현재 표준)으로 발전했습니다. 투영식 중 스테퍼는 웨이퍼를 옮겨 가며 한 영역씩 한 번에 찍고 스캐너는 마스크와 웨이퍼를 서로 반대로 움직이며 슬릿으로 훑어 큰 칩도 찍을 수 있고 해상도가 좋습니다.
5. PEB(노광 후 베이크): 화학증폭형 PR에서 빛으로 생긴 산을 확산시켜 반응을 증폭하고 PR 안에서 빛이 반사·간섭해 생기는 물결무늬(정재파)를 완화합니다.
6. 현상: 약알칼리 현상액으로 녹을 부분을 녹입니다. 담그는 이머전 방식(생산성), 뿌리는 스프레이 방식(미세 패턴), 천천히 돌리며 액을 고이게 하는 퍼들 방식(두 장점을 절충)이 있습니다.
7. 하드 베이크: 약 100 °C에서 남은 용매를 날려 PR을 단단하게 하고 접착을 높입니다. 과하면 식각 뒤 PR 제거가 어려워져 최적화가 필요합니다.
8. 검사(ADI): 패턴 크기(CD), 아래층과의 정렬(박스 인 박스 표식의 중심 어긋남을 X·Y로 측정하는 오버레이), 결함을 검사합니다. 불량이면 PR을 벗기고 다시 할 수 있다(리워크)는 점이 포토의 특징입니다.

![레일리 식의 세 손잡이: 광원 파장, 렌즈 NA, 공정 상수 k₁](../figures/3-4-2.svg)

**해상도를 정하는 빛의 원리**

1. 레일리 식: 해상도(구별할 수 있는 최소 간격) R = k₁λ/NA는 파장 λ가 짧을수록, NA(렌즈가 모을 수 있는 최대 회절각, n·sinθ)가 클수록, 공정 상수 k₁이 작을수록 작아집니다. 초점이 맞는 깊이 여유 DOF = k₂λ/NA²는 NA를 키우면 제곱으로 줄어, 해상도와 DOF는 맞바꾸는 관계입니다.
2. 회절과 간섭: 빛은 좁은 틈을 지나면 퍼지고(회절), 퍼진 빛끼리 겹쳐 밝고 어두운 무늬를 만듭니다(간섭). 마스크를 지난 빛은 0차·±1차 회절광으로 나뉘는데, 두 개 이상의 회절광이 렌즈에 들어와 간섭해야 웨이퍼에 무늬가 맺힙니다. 패턴이 작을수록 회절각이 커져 렌즈를 벗어나므로, 짧은 파장(회절각 감소)과 큰 렌즈(높은 NA)가 필요합니다.
3. k₁의 물리적 한계는 0.25입니다. 이보다 작으면 회절광이 렌즈 밖으로 나가 한 번의 노광으로는 무늬가 맺히지 않습니다.
4. low-k₁ 기술: OAI(빛을 비스듬히 넣어 정보가 없는 0차광 비중을 줄이고 회절광을 더 많이 모음 → 해상도와 DOF 개선), OPC(빛 번짐으로 모서리가 뭉툭해지거나 끝이 짧아지는 왜곡을 미리 계산해 마스크 모양을 보정), PSM(이웃 패턴을 지나는 빛의 위상을 반대로 만들어 상쇄 간섭으로 경계를 또렷하게), 멀티 패터닝이 있습니다.
5. 멀티 패터닝: 한 번에 못 그리는 촘촘한 패턴을 둘 이상으로 나눠 그립니다. LELE(노광-식각을 두 번), LFLE(첫 PR을 굳힌 뒤 다시 노광), SADP(심이 되는 맨드릴 양옆에 스페이서를 증착하고 맨드릴을 없애 스페이서를 패턴으로 씀 → 피치 절반), SAQP(SADP를 한 번 더 → 4분의 1)가 있습니다. 기존 ArF 장비로 미세화할 수 있어 EUV의 백업 기술이 되지만 증착·식각·CMP 단계가 늘어 원가가 오릅니다.
6. ArF 이머전: 렌즈와 웨이퍼 사이를 공기 대신 물(굴절률 약 1.44)로 채워 NA를 1.35까지 높였습니다. 해상도와 DOF가 함께 좋아지지만 물에 PR 성분이 녹아 나와 렌즈·패턴을 오염시키거나 미세 물방울이 결함을 만들 수 있어 소수성 PR과 탑코팅을 씁니다.

**EUV는 무엇이 다른가**

| 구분 | DUV(ArF) | EUV |
| --- | --- | --- |
| 파장 | 193 nm | 13.5 nm |
| 광원 | 엑시머 레이저 | 주석(Sn) 방울에 CO₂ 레이저를 초당 약 5만 번 쏘아 만든 플라즈마(LPP) |
| 광학계 | 렌즈 수십 장(투과형) | 거울(반사형), Mo/Si 다층막 브래그 거울 |
| 마스크 | 투과형 | 반사형, Ta 계열 흡수체로 패턴 |
| 환경 | 대기압 | 진공(거의 모든 물질이 EUV를 흡수하고 입자에 산란됨) |
| PR | 화학증폭형(CAR) | 고감도 CAR, 금속산화물(무기) PR, 드라이 레지스트 |

- 브래그 거울: 굴절률이 다른 Mo와 Si를 수십 쌍 번갈아 쌓고 각 층 두께를 계면마다 반사된 빛이 보강 간섭하도록(브래그 조건) 맞춥니다. 그래도 거울 한 장의 반사율은 약 60\~70%라, 광원에서 웨이퍼까지 마스크를 포함해 10장이 넘는 거울을 거치면 빛의 아주 일부만 남습니다. 그래서 광원 출력과 광효율이 생산성의 핵심입니다.
- 광효율 높이기: 약한 프리펄스로 주석 방울을 납작한 원반으로 펴 레이저가 잘 흡수되게 하고 메인 CO₂ 레이저의 출력·초점·타이밍을 맞춰 13.5 nm 빛을 많이 내는 플라즈마 조건을 만듭니다. 주석 부스러기가 빛을 모으는 거울(콜렉터)을 오염시키지 않게 하는 것도 중요합니다.
- 마스크 3D 효과: EUV는 마스크에 약 6° 비스듬히 들어오는데, 흡수체가 두께를 가지고 튀어나와 있어 그림자(섀도잉)와 상의 왜곡이 생깁니다. 더 얇은 흡수체나 새 흡수체 재료를 개발합니다.
- 펠리클: 수억 원짜리 마스크를 먼지에서 보호하는 초박막인데, EUV는 반사형이라 빛이 펠리클을 두 번 지나며 손실이 커서, 투과율과 열에 강한 펠리클이 과제입니다.
- 광자 수와 선 거칠기: EUV 광자는 에너지가 커서 같은 노광량을 적은 수의 광자로 채웁니다. 구슬(KrF)로 1 m 줄을 만들면 매끈하지만 축구공(EUV)으로 만들면 울퉁불퉁한 것처럼, 광자가 적으면 선 가장자리가 거칠어집니다(LER 증가). 해상도(R), 선 거칠기(L), 감도(S)는 하나를 좋게 하면 다른 것이 나빠지는 RLS 트레이드오프 관계입니다.
- EUV 전용 PR: EUV 광자는 PR 수지에 먼저 흡수돼 2차 전자를 만들고 이 2차 전자가 PAG를 활성화해 산을 만드는 단계가 하나 더 있어 효율이 떨어집니다. 그래서 EUV를 잘 흡수하는 주석 기반 무기 PR(유기 껍질에 싸인 나노입자가 빛을 받으면 껍질이 벗겨지고 서로 결합해 굳는 음성 PR, 식각 내성이 좋아 더 얇게 쓸 수 있음)과, 용액 대신 기체로 증착하는 드라이 레지스트(현상액이 마를 때 표면 장력으로 패턴이 쓰러지는 문제 해결, 균일한 박막)가 개발됐습니다. PR을 너무 얇게 만들면 다음 식각을 견디지 못하므로 식각 내성도 핵심 조건입니다.
- High-NA EUV: NA를 0.33에서 0.55로 키운 장비입니다. 거울이 커지면 입사광과 반사광이 겹치므로 가로·세로 축소 배율을 다르게 하는 아나모픽 광학(한 번에 찍는 영역이 절반 → 두 번 찍어 잇고 마스크를 더 빨리 움직여 생산성 보완)과 광로 각도를 바꾼 옵스큐레이션 구조를 씁니다(4-2).

**PR(감광액)**

| 구분 | 양성 PR | 음성 PR |
| --- | --- | --- |
| 빛 받은 곳 | 보호기가 떨어져 산이 생기고 현상액에 녹음 | 고분자끼리 가교 결합해 굳어 남음 |
| 해상도·대비 | 높음 | 현상액을 머금고 부풀어(스웰링) 낮음 |
| 쓰임 | 대부분의 미세 공정 | 저렴해 패키징 등, EUV 무기 PR |

| 구분 | 노볼락 PR | 화학증폭형 PR(CAR) |
| --- | --- | --- |
| 광원 | g·i-line(램프) | KrF·ArF·EUV |
| 원리 | 감광제(PAC)가 녹지 않게 막다가 빛을 받으면 풀림(용해 억제형) | 광산 발생제(PAG)가 빛을 받아 산을 만들고 PEB에서 산이 연쇄 반응(화학 증폭) |
| 왜 바뀌었나 | 램프는 빛이 강해 감도가 낮아도 됨 | 레이저는 빛이 약해 적은 빛에도 반응하는 고감도 PR 필요, 노볼락은 DUV를 너무 흡수 |

PR을 고를 때는 해상도, 감도(적은 에너지로 반응 → 생산성), 대비(노광·비노광의 용해도 차이), 식각 내성, 선 거칠기를 함께 봅니다. PR은 유기물이라 시간이 지나면 특성이 변해 수명 관리도 중요합니다.

**CD, 피치, 산포** CD(Critical Dimension)는 패턴의 크기(라인 폭, 스페이스, 홀 지름), 피치는 반복되는 패턴의 주기입니다. 게이트 길이(CD)가 문턱전압을 정하므로 CD의 산포는 곧 문턱전압 산포이고 이는 속도·누설·소자 간 불일치로 이어집니다. 양성 PR 라인을 과노광하면 산이 더 많이 생기고 퍼져 CD가 가늘어집니다. 이를 이용해 노광량으로 CD를 조절하기도 하지만 확산은 정밀 제어가 어려워 무작정 늘릴 수는 없습니다. 그래서 초기 조건은 초점과 노광량을 바둑판처럼 바꿔 찍은 FEM(Focus Exposure Matrix) 웨이퍼로 최적점을 찾습니다.

**면접 단골 질문**

- Q. 포토 공정 순서를 말해 보세요. → 전처리(HMDS) → 코팅 → 소프트 베이크 → 정렬·노광 → PEB → 현상 → 하드 베이크 → 검사. 각 단계의 목적을 한 마디씩 붙입니다.
- Q. 레일리 식을 설명하고 해상도를 높이는 방법은? → λ를 줄이고(KrF→ArF→EUV), NA를 키우고(이머전, High-NA), k₁을 줄인다(OAI·OPC·PSM·멀티 패터닝). NA를 키우면 DOF가 줄어드는 트레이드오프까지 말합니다.
- Q. EUV와 DUV의 차이는? → 광원(플라즈마), 광학계(반사형), 마스크(반사형), PR(고감도·무기), 진공 환경 다섯 가지로 나눠 답합니다.
- Q. EUV를 도입한 이유는? → ArF 이머전의 한계를 멀티 패터닝으로 넘기면 공정 수와 원가가 늘어나므로, 한 번의 노광으로 미세 패턴을 그려 공정을 줄이고 원가를 낮추기 위해서입니다.
- Q. PR 감도는 높을수록 좋은가요? → 적은 에너지로 패턴을 만들어 생산성은 좋아지지만 광자 수가 줄어 선 거칠기가 나빠집니다. 해상도와 LER을 만족하는 조건에서 감도가 높아야 한다(RLS)고 답합니다.
- Q. 과노광하면 CD는? → 양성 PR 라인은 가늘어집니다. 산이 더 많이 생기고 확산되기 때문입니다.
- Q. 양성 PR이 음성 PR보다 해상도가 좋은 이유는? → 음성 PR은 가교된 고분자 사이로 현상액이 스며들어 부풀기(스웰링) 때문입니다.

**관련 뉴스 태그** `EUV` `High-NA` `ASML` `포토레지스트` `펠리클`

**더 깊이** 마스크에 직선만 쓰던 관행을 깨고 곡선 패턴을 넣는 곡선 마스크(curvilinear mask)는 빛의 번짐을 더 정확히 보정해 공간 효율과 수율을 높입니다.
