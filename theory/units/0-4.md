# 0-4 반도체는 어디에 쓰이나

면접 빈도 ★ · 이어지는 단원: 4-7 AI 반도체와 메모리

**한 줄 정의** 모든 전자기기는 '계산하는 칩 + 가까이 두는 메모리(D램) + 오래 저장하는 메모리(낸드) + 전원·통신 칩'으로 이뤄져 있고 기기마다 규모와 성능만 다릅니다.

**비유** 스마트폰은 혼자 일하는 1인 사무실, AI 서버는 수천 명이 일하는 공장입니다. 둘 다 직원(연산), 책상(D램), 창고(낸드), 전기와 전화(전원·통신)가 필요합니다.

![스마트폰과 AI 서버 속 칩 지도 · 각 8종](../figures/0-4-1.svg)

색을 칠한 칸이 기기의 중심입니다. AI 서버에서는 GPU만큼 HBM이 중심이라는 점이 핵심입니다.

**원리**

1. 스마트폰: AP 하나에 CPU·GPU·NPU·모뎀을 모았습니다. 배터리로 돌아가니 모든 칩이 '저전력'이 최우선입니다(LPDDR의 LP = Low Power).
2. AI 서버: GPU는 수천 개의 단순 계산기를 동시에 돌립니다. 계산기가 놀지 않게 데이터를 쏟아주려고 HBM을 GPU 바로 옆에 붙입니다.
3. AI 모델이 커질수록 계산보다 '데이터를 옮기는 일'이 더 비싸집니다. SK하이닉스 뉴스룸 기고는 D램에서 데이터를 한 번 가져오는 에너지가 단순 연산의 150\~2,000배이고 대형 모델에서는 시스템 에너지의 90% 이상이 메모리 접근과 데이터 이동에 쓰일 수 있다고 설명합니다([SK hynix Newsroom](https://news.skhynix.com/en/ai-ecosystem-series-ep3/)).

**용도별 메모리 이름 정리**

| 이름 | 종류 | 어디에 |
| --- | --- | --- |
| HBM | D램을 수직으로 쌓은 고대역폭 메모리 | AI 가속기(GPU·ASIC) |
| DDR5 | 표준 D램 | 서버·PC의 CPU |
| LPDDR5X·6 | 저전력 D램 | 스마트폰, 온디바이스 AI, 일부 AI 서버 |
| GDDR7 | 그래픽용 D램 | 그래픽카드 |
| eSSD | 낸드 기반 기업용 SSD | 데이터센터 저장 |
| UFS | 낸드 기반 모바일 저장장치 | 스마트폰 |

**면접 단골 질문**

- Q. AI 시대에 왜 메모리가 중요해졌나요? → 뼈대: ① AI 계산은 같은 데이터를 반복해서 읽음 ② 계산 속도보다 메모리에서 데이터를 가져오는 속도·에너지가 병목(메모리 벽) ③ 그래서 가까이, 넓게 연결하는 HBM이 핵심 부품이 됨.
- Q. 온디바이스 AI는 반도체 수요를 어떻게 바꾸나요? → 스마트폰·PC 안에서 AI를 돌리려면 NPU와 더 큰 LPDDR 용량이 필요합니다. 기기당 D램 탑재량이 늘어납니다.

**관련 뉴스 태그** `AI 서버` `HBM` `eSSD` `온디바이스 AI` — SK하이닉스는 2026년 2분기 실적에서 AI 서버용 고성능 제품(HBM, 서버 D램, eSSD)이 가격 상승을 이끌었다고 밝혔습니다([SK hynix Newsroom](https://news.skhynix.com/en/q2-2026-business-results/)).

**더 깊이** AI 데이터센터는 GPU 수천 개를 네트워크로 묶기 때문에 칩 사이 연결(NVLink, CXL)과 전력·냉각이 새 병목이 되고 있습니다(4-7, 4-9).
