# 3-17 메모리 테스트와 불량 분석: PE가 하는 일

면접 빈도 ★★(PE·품질보증·양산기술(P&T) 직무는 ★★★) · 이어지는 단원: 2-10 D램 동작 심화, 2-11 낸드 동작 심화, 3-11 EDS와 테스트, 3-13 수율·결함, 4-9 열·전력·신뢰성

**한 줄 정의** 메모리 테스트는 수십억 개 셀이 규격 안의 전압·온도·속도에서 모두 제대로 동작하는지 정해진 패턴으로 확인해 불량을 고치거나 걸러내는 일이고, 불량 분석은 실패한 비트의 모양과 조건에서 출발해 전기적·물리적 분석으로 소자·공정의 원인을 찾아 되돌려 주는 일입니다.

**비유** 건강검진과 정밀검사입니다. 테스트는 모든 사람에게 같은 항목의 검진(패턴)을 해서 이상이 있는 사람을 골라내는 단계이고, 불량 분석은 이상이 나온 사람을 혈액검사(전기적 분석) → 영상 촬영(위치 찾기) → 조직검사(물리 분석) 순서로 좁혀 병명을 찾는 단계입니다.

![출하까지의 테스트(위), 불량 비트 지도 모양과 의심 원인(왼쪽 아래), 불량 분석 순서(오른쪽 아래)](../figures/3-17-1.svg)

위는 메모리가 출하되기까지 거치는 테스트 단계, 왼쪽 아래는 불량 비트 지도(FBM)의 대표 모양과 의심 원인, 오른쪽 아래는 불량 하나를 끝까지 추적하는 분석 순서입니다.

**원리**

1. 테스트의 세 가지 목적: 불량 선별(좋은 칩만 출하), 등급 분류(속도·전력별로 나누기), 피드백(설계·소자·공정 부서로 데이터 전달). PE의 Test Engineering은 이 셋을 모두 만족하면서도 테스트 시간을 줄이는 기준을 만드는 일입니다. 테스트 시간이 곧 비용이기 때문입니다.
2. 테스트 항목: DC 테스트(누설 전류, 대기·동작 전류, 입출력 전압), 기능 테스트(패턴을 써넣고 읽어 비교), AC·타이밍 테스트(tRCD·tRP 같은 여유), 리텐션 테스트(데이터를 쓰고 리프레시를 일부러 멈춘 채 기다렸다가 읽기), 교란 테스트(로우해머·이웃 셀 간섭 패턴). 낸드는 쓰기·지우기 시간, 배드 블록, P/E 반복 뒤의 특성을 봅니다.
3. 테스트 패턴: 모두 0·모두 1, 체커보드(0과 1을 바둑판처럼), 행·열 줄무늬, 0과 1을 하나씩 옮기는 워킹 패턴, 주소를 올렸다 내렸다 하며 읽고 쓰는 March 계열(예: March C−)이 대표적입니다. 패턴마다 잘 잡는 불량(값이 고정된 셀, 이웃 셀끼리의 결합, 주소 디코더 불량, 간섭)이 다릅니다.
4. 조건을 흔들어 여유 보기: 같은 패턴이라도 전압을 낮추고 온도를 올리고 타이밍을 조이면 약한 셀이 먼저 드러납니다. 전압과 타이밍을 두 축으로 통과·실패를 찍은 그림이 쉬무 플롯(shmoo plot)이고, 통과 영역이 넓을수록 여유가 큰 제품입니다.
5. 리페어와 등급: 웨이퍼 테스트에서 찾은 불량 행·열은 예비 행·열(리던던시)로 바꿉니다(3-11). 패키지 이후에 생긴 불량도 일부는 퓨즈를 이용해 고칠 수 있습니다(PPR). 남는 칩은 속도·전력에 따라 등급을 나눕니다.
6. 불량 비트 지도(FBM): 실패한 비트를 실제 위치에 찍으면 모양이 원인을 알려 줍니다. 흩어진 단일 비트는 약한 셀·리텐션, 한 줄 전체는 워드라인(행)이나 비트라인·감지 증폭기(열), 뭉친 덩어리는 파티클·국부 공정 이상, 웨이퍼 위치별로 반복되면 장비나 노광 샷 문제를 의심합니다(3-13).
7. 전기적 분석: 불량 칩을 다시 측정해 재현 조건(전압·온도·패턴·타이밍)을 찾고, 의심 부위의 I-V를 재며, 나노 프로빙으로 트랜지스터 하나의 특성까지 측정합니다.
8. 위치 찾기와 물리 분석: 전압을 걸었을 때 결함 부위가 내는 아주 약한 빛(EMMI)이나 저항·열의 변화(OBIRCH, 열화상)로 위치를 좁힌 뒤, 층을 한 겹씩 벗기고(디프로세싱) 집속 이온빔(FIB)으로 단면을 잘라 SEM·TEM으로 보고 EDX로 성분을 확인합니다. 패키지 불량은 X선·초음파(SAT)로 내부의 끊김과 들뜸을 먼저 봅니다.
9. 원인 피드백과 고객 불량: 찾은 원인을 소자·공정·설계 부서에 넘기고, 조건을 바꾼 뒤 수율과 신뢰성이 실제로 좋아졌는지 다시 검증합니다. 고객 시스템(Application)에서 난 불량은 고객 환경을 재현하는 시스템 테스트로 먼저 확인합니다.
10. 데이터: 웨이퍼·패키지·모듈 테스트 결과와 공정 이력을 이어 분석하면, 어떤 공정 조건이 어떤 불량 모양과 함께 다니는지 찾을 수 있습니다. PE JD가 테스트 프로그램 개선과 빅데이터 분석, 프로그래밍 역량을 함께 요구하는 이유입니다.

**불량 비트 모양과 의심 원인**

| FBM 모양 | 의심 원인 | 확인 방법 |
| --- | --- | --- |
| 흩어진 단일 비트 | 약한 셀(리텐션), 셀 누설, 커패시터 이상 | 온도·대기 시간을 바꾼 리텐션 테스트 |
| 한 행 전체 | 워드라인 끊김·단락, 행 디코더 | 행 주소 패턴, 워드라인 저항·누설 측정 |
| 한 열 전체 | 비트라인 단락, 감지 증폭기, 열 디코더 | 열 패턴, 감지 증폭기 쪽 전기적 분석 |
| 이웃 두 비트 | 셀 사이 단락(콘택·랜딩 패드 붙음) | 체커보드 패턴, 단면 분석 |
| 덩어리 | 파티클, 국부 식각·증착 이상 | 결함 검사 이력과 위치 대조(3-13) |
| 웨이퍼 가장자리·특정 샷 | 장비·노광·막 두께 산포 | 웨이퍼 맵, 장비 이력 공통점 분석 |

**불량 분석 도구**

| 도구 | 무엇을 보나 | 파괴 여부 |
| --- | --- | --- |
| 테스터(ATE)·FBM | 어떤 비트가 어떤 조건에서 실패하나 | 비파괴 |
| EMMI·OBIRCH·열화상 | 결함이 내는 빛, 저항·열 변화의 위치 | 비파괴 |
| X선·초음파(SAT) | 패키지 내부 끊김·들뜸 | 비파괴 |
| 나노 프로빙 | 트랜지스터 하나의 I-V | 파괴(층을 벗겨야 함) |
| 디프로세싱·FIB | 층 벗기기, 원하는 위치의 단면 | 파괴 |
| SEM·TEM·EDX | 모양, 결정, 성분 | 파괴 |

**면접 단골 질문**

- Q. PE 직무는 어떤 일을 한다고 생각하나요? → 제품의 특성·품질·양산성을 모두 만족하는 테스트 기준을 만들고(Test Engineering), 메모리 동작을 해석해 설계·공정 특성을 검증하며(제품 검증), 테스트 프로그램과 데이터로 품질 관리 체계를 개선하고(Test Solution 개발), 불량을 전기적·물리적으로 분석해 원인을 찾는 일(불량 분석)입니다. JD의 네 가지에 내가 공부한 단원을 하나씩 연결해 답합니다.
- Q. 수율이 떨어진 D램 웨이퍼를 받았다면? → 웨이퍼 맵과 FBM으로 모양 분류 → 재현 조건(온도·전압·패턴) 확인 → 공정 이력 공통점 분석 → 전기적·물리적 분석 → 원인 공정 피드백 → 개선 검증(3-13, 6-3).
- Q. 리텐션 불량은 어떻게 찾고 분석하나요? → 데이터를 쓰고 리프레시를 멈춘 채 고온에서 기다렸다 읽는 테스트 → 실패 비트의 분포와 온도 의존성 확인 → 셀 누설 경로(접합, GIDL, 유전막) 가설 → 해당 구조 분석.
- Q. 테스트 시간을 줄이는 방법은? → 여러 칩 동시 측정(멀티 사이트), 칩 안 자체 테스트 회로(BIST), 중복 항목 정리, 데이터로 불필요한 항목을 빼되 불량 유출이 늘지 않는지 검증.
- Q. 쉬무 플롯이란? → 전압·타이밍 같은 두 조건을 축으로 통과·실패를 찍은 그림입니다. 통과 영역의 넓이가 동작 여유이고, 경계 모양을 보면 어떤 한계(속도·전압)에 걸리는지 짐작할 수 있습니다.
- Q. 고객 불량을 받았을 때의 순서는? → 고객 환경 재현 → 칩 단위 테스트로 불량 확인 → 내부 테스트·공정 이력과 대조 → 분석 → 대책과 재발 방지 보고.

**관련 뉴스 태그** `HBM 테스트` `KGD` `수율` `품질`

**더 깊이** HBM은 D램 여러 장을 쌓은 뒤에는 고치거나 바꾸기 어려워, 쌓기 전에 좋은 다이만 고르는 KGD 테스트와 쌓은 뒤의 테스트가 모두 중요합니다(4-5). 테스트 데이터가 커질수록 웨이퍼 맵 불량 패턴을 자동으로 분류하는 머신러닝도 PE·양산 현장에서 쓰입니다.
