# 3-14 CMOS 전체 공정 흐름: 10개 모듈로 칩 하나 완성하기

면접 빈도 ★★(공정기술·소자 직무는 ★★★, PT 문제의 바탕) · 이어지는 단원: 2-2 MOSFET, 2-4 CMOS, 3-1\~3-10 각 공정, 3-15·3-16 메모리 공정 흐름

**한 줄 정의** 8대 공정은 '도구'이고 실제 칩은 이 도구들을 정해진 순서로 수백 번 조합해 만듭니다. CMOS 로직의 기본 흐름은 소자 분리 → 웰 → 문턱 전압 조절 → 게이트 → LDD·스페이서 → 소스/드레인 → 살리사이드 → 콘택 → 금속 배선 → 보호막의 10개 모듈로 정리할 수 있습니다.

**비유** 집 짓기 순서와 같습니다. 땅을 구획하고(소자 분리), 기초를 다지고(웰), 문틀을 세우고(게이트), 문틀 옆 마감(스페이서)과 출입구(소스/드레인)를 만든 뒤, 전선을 깔고(콘택·배선) 지붕을 덮습니다(보호막). 순서가 바뀌면 앞서 만든 것이 망가집니다.

![CMOS 공정 흐름을 여섯 컷의 단면으로(왼쪽 NMOS, 오른쪽 PMOS)](../figures/3-14-1.svg)

각 칸은 앞 칸 위에 공정을 더한 단면입니다. 왼쪽 절반은 NMOS, 오른쪽 절반은 PMOS이며 가운데 홈이 둘을 가르는 STI입니다.

**모듈별 흐름(합격자 필기 기준)**

1. 소자 분리(Isolation): 이웃 소자(특히 N-well과 P-well 사이)로 전류가 새지 않게 절연 벽을 만듭니다. 예전엔 실리콘을 국부적으로 산화시키는 LOCOS를 썼지만 가장자리가 새 부리(bird's beak) 모양으로 번져 면적을 잃었고 지금은 얕은 홈을 파고 산화막으로 채우는 STI를 씁니다. 순서: P형 (100) 웨이퍼 투입 → 버퍼 산화막 → 질화막(Si₃N₄, LPCVD 약 900 °C, 나중에 CMP 정지층) → 반사 방지막(BARC·SiON) → 포토 → 질화막 식각 → PR 제거 → 실리콘 트렌치 식각 → 라이너 산화막·라이너 질화막 → HDP-CVD로 산화막 채우기 → 뒷면 질화막 제거 → 어닐로 치밀화 → STI CMP(질화막에서 멈춤) → 질화막 제거 → 버퍼 산화막 제거.
2. 웰(Well): 사전 세정 → 버퍼(스크린) 산화막 → N-well 포토 → 인(P) 주입 → PR 애싱 → P-well 포토 → 붕소(B) 주입 → PR 애싱 → 드라이브 인 어닐(불순물을 깊게 확산시키고 활성화).
3. 문턱 전압·펀치스루 주입(VT/PT): 채널 표면의 도핑 농도를 미세 조정해 Vth를 맞추고(VT 주입), 그보다 깊은 곳에 주입해 소스와 드레인의 공핍층이 맞닿는 펀치스루를 막습니다(PT 주입). 산화막 제거 → 세정 → 스크린 산화막 → NMOS·PMOS 각각 포토 후 주입(필기 예: PMOS 쪽 VT는 비소(As), PT는 인(P)) 순입니다.
4. 게이트: 게이트 산화막 성장(고전압 회로용 두꺼운 HV, 저전압 회로용 얇은 LV를 구분) → 폴리실리콘 증착(LPCVD) → 게이트 포토·식각 → 재산화(식각 손상 회복). 산화막 속 전하는 계면 포획 전하, 고정 전하, 이동성 이온 전하(Na⁺ 등), 산화막 포획 전하 네 가지로, Vth를 흔들기 때문에 관리합니다(3-3).
5. LDD·스페이서: 게이트를 마스크로 삼아 얕고 옅게 주입(LDD: NMOS는 As를 0°, PMOS는 BF₂)해 드레인 근처 전기장을 낮춰 핫 캐리어를 줄이고 45° 기울여 반대 타입을 넣는 할로(halo) 주입으로 짧은 채널 효과를 막습니다. 그다음 산화막(PECVD)을 덮고 전면 식각(etch-back)하면 게이트 옆에만 남는 스페이서가 생깁니다. 마스크 없이 저절로 위치가 정해지는 자기 정렬(self-aligned)입니다.
6. 소스/드레인(S/D): 스페이서를 마스크로 깊고 진하게 주입(NMOS는 As, PMOS는 BF₂, 채널링을 피하려 약 7° 기울임) → 급속 열처리(RTA, 약 10초)로 활성화. LDD는 스페이서 아래에 남아 완충 역할을 합니다.
7. 살리사이드(Salicide): 소스·드레인·게이트 위에만 금속 실리사이드를 자기 정렬로 만들어 접촉 저항을 낮춥니다. 사전 비정질화 주입(PAI) → 세정(BHF) → 금속(Ti·Co·Ni) 증착(PVD) → 1차 어닐(낮은 온도, 고저항상 형성) → 반응하지 않은 금속을 SPM으로 제거 → 2차 어닐(높은 온도, 저저항상으로 변환). 1차·2차 온도는 합격자 필기에서 650 °C·850 °C, 타이핑 자료에서 750 °C·900 °C로 다르며 금속 종류와 공정에 따라 달라집니다(3-9).
8. 콘택: 층간 절연막(ILD1 SiON, ILD2 SiO₂) 증착 → ILD CMP → 반사 방지막(SiON)·하드마스크(탄소) → 콘택 포토 → RIE 식각 → PR 제거 → 배리어(Ti/TiN) → 텅스텐(W) 채움 → W CMP → 세정.
9. 금속 배선: 알루미늄 방식은 Ti/TiN → Al → TiN 증착 후 포토·RIE로 깎고 합금 어닐, 층 사이는 비아와 W 플러그로 잇습니다. 구리 방식은 IMD 증착 → 비아·트렌치 식각(듀얼 다마신) → TaN/Ta 배리어 → Cu 씨드 → 전해 도금 → Cu CMP → 캐핑막 순입니다(3-9).
10. 보호막(Passivation): 산화막·질화막을 덮어 습기·이온·긁힘을 막고 외부와 연결할 패드만 포토·식각으로 엽니다 → PR 제거 → 합금 어닐 → 검사 → 웨이퍼 ET(PCM 테스트) → EDS(3-11).

**한눈에 보는 모듈 표**

| 모듈 | 목적 | 핵심 공정 | 대표 이슈 |
| --- | --- | --- | --- |
| 소자 분리 | 소자 간 누설 차단 | 트렌치 식각, HDP 채움, STI CMP | 보이드, 디싱, 모서리 누설 |
| 웰 | NMOS·PMOS의 바탕 | 이온 주입, 드라이브 인 | 래치업 |
| VT/PT | Vth 조절, 펀치스루 방지 | 에너지를 달리한 주입 | Vth 산포 |
| 게이트 | 스위치의 손잡이 | 게이트 산화, 폴리 증착, 게이트 식각 | 산화막 두께, 게이트 CD |
| LDD·스페이서 | 핫 캐리어·짧은 채널 효과 억제 | 저농도 주입, 할로, 스페이서 식각 | 스페이서 폭 |
| 소스/드레인 | 전류의 출입구 | 고농도 주입, RTA | 접합 깊이, 누설 |
| 살리사이드 | 접촉 저항 감소 | 금속 증착, 2단계 어닐 | 브리징, 응집 |
| 콘택 | 소자와 배선 연결 | ILD, 콘택 식각, W 채움 | 고종횡비 보이드, 미개통 |
| 금속 배선 | 신호·전원 전달 | 다마신, Cu 도금, CMP | RC 지연, EM |
| 보호막 | 외부 환경 차단 | 산화막·질화막, 패드 오픈 | 크랙, 패드 오염 |

**FEOL·MOL·BEOL과 온도 순서** 트랜지스터를 만드는 1\~7을 FEOL, 콘택(8)을 MOL, 배선(9\~10)을 BEOL이라고 부릅니다. 높은 온도가 필요한 공정(산화, 드라이브 인)은 앞에 두고 금속이 들어간 뒤에는 대략 400\~450 °C 이하의 공정만 씁니다. 앞에서 받은 열의 총량(thermal budget)이 도핑 분포를 퍼뜨리고 금속을 상하게 하기 때문입니다.

**면접 단골 질문**

- Q. CMOS 공정 흐름을 순서대로 설명해 보세요. → 10개 모듈을 목적과 함께 한 줄씩.
- Q. STI가 LOCOS보다 좋은 이유는? → 새 부리 없이 좁은 폭에서 깊게 절연할 수 있고 CMP로 표면이 평탄합니다.
- Q. LDD와 할로 주입을 하는 이유는? → 드레인 전기장 완화(핫 캐리어) / 짧은 채널 효과·펀치스루 억제.
- Q. 스페이서의 역할은? → LDD와 S/D의 위치를 자기 정렬로 나누고 살리사이드 때 게이트와 S/D가 이어지는 단락을 막습니다.
- Q. 살리사이드를 2단계로 어닐하는 이유는? → 1차는 낮은 온도에서 반응만 시켜 스페이서 위로 번지는 브리징을 막고 미반응 금속을 없앤 뒤 2차에서 저저항상으로 바꿉니다.
- Q. 이온 주입 때 기울이는 이유는? → 결정 방향을 따라 깊이 들어가는 채널링 방지(3-8).
- Q. 공정 순서에서 온도가 중요한 이유는? → 열 이력이 도핑 분포와 금속을 망가뜨리지 않도록.

**관련 뉴스 태그** `CMOS` `FEOL` `BEOL` `공정 미세화`

**더 깊이** FinFET·GAA에서는 핀·나노시트 형성, 대체 금속 게이트(HKMG), 에피택시 소스/드레인이 더해집니다(2-5, 4-1). 메모리(DRAM)는 여기에 매몰 채널(BCAT)과 커패시터 모듈이 추가됩니다(2-7).
