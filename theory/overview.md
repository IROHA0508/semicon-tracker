2026-10-05 · 시원

## 읽는 법

모든 단원은 같은 7칸 틀로 쓰여 있어, 어느 단원을 펼쳐도 같은 자리에서 같은 종류의 정보를 찾을 수 있습니다. 단원 제목 바로 아래 줄에는 면접 빈도(별표)와 함께 읽으면 좋은 단원이, 단원 맨 끝에는 그 단원에 반영한 자료가 적혀 있습니다.

## 학습 경로

**최소 핵심 경로: 시간이 없을 때 ★★★ 26단원부터**

아래 순서대로 읽으면 앞 단원의 원리가 다음 단원에서 바로 쓰입니다. 하루 2\~3단원씩이면 2주 안팎이 걸립니다.

1. 큰 그림과 기초(3단원): 0-2 칩의 일생 → 0-3 반도체의 종류 → 1-5 도핑과 캐리어. 1-5가 어렵게 느껴지면 1-3 에너지 밴드를 먼저 봅니다.
2. 소자(9단원): 2-1 PN 접합 → 2-2 MOSFET 구조와 동작 → 2-3 MOSFET 특성 → 2-4 CMOS → 2-5 미세화와 한계 → 2-6 트랜지스터 구조 진화 → 2-7 메모리 계층과 SRAM·DRAM → 2-8 NAND 플래시 → 2-10 D램 동작 심화
3. 공정(10단원): 3-3 산화 → 3-4 포토 → 3-5 플라즈마 기초 → 3-6 식각 → 3-7 증착 → 3-8 이온주입과 열처리 → 3-9 금속배선 → 3-13 수율·결함·계측·데이터 → 3-15 D램 공정 흐름 → 3-16 3D 낸드 공정 흐름
4. 메모리 산업(4단원): 4-3 D램 심화 → 4-5 HBM → 4-7 AI 반도체와 메모리 → 5-3 메모리 사이클

마무리로 3-14 CMOS 전체 공정 흐름을 백지에 그려 보고, 6-2 단골 질문 은행으로 1분 답변을 연습합니다.

**Product Engineering(PE) 지원자라면** 위 26단원에 2-11 낸드 동작 심화, 3-11 EDS·번인, 3-17 메모리 테스트와 불량 분석, 4-9 열·전력·신뢰성을 더하고, 6층 6-1의 'PE 집중 경로' 다섯 단계 순서대로 읽습니다. 이 원고는 SK하이닉스 2026 하반기 JD의 PE 직무를 기준 직무로 삼아 메모리 동작·공정·테스트 단원을 보강했습니다.
