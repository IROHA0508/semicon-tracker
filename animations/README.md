## 보는 법

`python -m http.server -d animations` 후 `http://localhost:8000`을 엽니다. ← → 키로 단계 이동, Space로 자동 재생, Home·End로 처음·끝. 모드가 있는 페이지는 `dram-cell.html#write`처럼 주소 끝에 모드를 붙여 바로 열 수 있습니다.

## 새 애니메이션 만들기

1. SVG에 바뀌는 요소마다 `id`와 `class="t"`를 붙입니다.
2. 페이지 스크립트에서 `StepPlayer.create({ root, base, steps })`를 부릅니다. 모드가 여럿이면 `modes: [{ id, label, base, steps }]`.
3. 각 단계는 `{ short, title, text, cmd, set, hl }`입니다. `set`은 그 단계부터 유지되는 상태이고, 단계 k의 그림은 base + 0..k 단계의 `set`을 차례로 합친 결과라서 어느 단계로 건너뛰어도 같은 그림이 나옵니다.
   - `s`: `data-s` 값. `off`는 숨김이고, 나머지 값(`on`, `void`, `idle` 등)은 페이지 CSS가 모양을 정합니다.
   - `style`: 인라인 스타일(주로 `transform`). CSS 전환으로 움직입니다.
   - `attr`, `text`, `num`(숫자를 세면서 바꿈).
   - 값 자리에 `(ctx) => ...` 함수를 쓰면 토글(예: 저장 값 1·0)에 따라 다시 그립니다.
4. `catalog.json`에 추가하고 `python -m pytest tests/test_animations.py`로 확인합니다.

## 움직임(공통 플레이어가 자동으로 넣음)

페이지마다 따로 쓰지 않아도 플레이어가 모든 페이지에 같은 효과를 넣습니다. 끝 그림(단계마다 멈춘 모습)은 효과가 없을 때와 같습니다.

- 단계가 바뀌면 바뀌는 요소가 모두 부드럽게 넘어갑니다. `class="t"`를 붙이지 않은 요소도 플레이어가 `sp-tt`를 붙여 투명도·색·위치가 서서히 바뀝니다.
- `attr`(선 모양 `d`, 좌표 `x`·`y`, `width` 등)과 `num`은 순간 이동하지 않고 0.7초 동안 이어서 바뀝니다. 숫자 개수나 형태가 다른 값은 바로 바뀝니다.
- **다음 단계로 한 칸 갈 때만**(다음 버튼, → 키, 자동 재생): 바뀌는 요소가 그림 순서대로 0.07초씩 차례로 시작하고(최대 0.56초), 새로 나타나는 선은 그려지듯 나타나고(점선·화살표 선 제외), 바뀐 글자는 서서히 나타나고, 강조된 부분은 한 번 굵어졌다 돌아옵니다. 뒤로 가기·건너뛰기·모드 전환·토글은 차례 없이 바로 갑니다.
- 오른쪽 단계 제목과 설명은 살짝 떠오르며 바뀝니다.
- 기기에서 '동작 줄이기'를 켜면 모든 효과가 꺼지고 바로 바뀝니다.
- `window.__player.settle()`은 진행 중인 효과를 모두 끝 상태로 보냅니다(화면 확인용).

## 영상 페이지 (시간 흐름으로 보는 애니메이션)

단계를 넘기는 대신 처음부터 끝까지 이어서 보는 페이지입니다. `dram-film.html`이 첫 번째 예시이고, 앞으로 만드는 영상도 같은 기준을 지킵니다.

- 가로 16:9, 길이 2분 이내, 장면 5~8개를 이어 붙인 흐름. 소리는 없고 자막으로 설명합니다.
- 모든 그림은 영상 시간 `t`의 함수입니다. 어느 시각으로 건너뛰어도 같은 그림이 나옵니다(`window.__film.seek(t)`).
- 재생·일시정지, 탐색 막대(장면 눈금), 장면 버튼, 속도 0.75~1.5배, 자막 켜기·끄기, 전체 화면, 단축키(Space, ←/→ ±5초, Home, F)를 갖춥니다.
- `player.css`를 쓰고(밝은·어두운 테마), 바깥 자원은 Google Fonts뿐입니다. `?embed`일 때 머리말과 노트를 숨기고 `st-anim-height`를 보냅니다.
- `catalog.json`의 `films`에 `{ id, unit, title, file, seconds, chapters, summary }`로 등록하면 단원 페이지(`영상으로 보기`)와 목록 페이지(영상 구역)에 나옵니다. 단계 애니메이션 목록(`animations`)과는 따로 셉니다.

## 사이트 단원 페이지에 넣을 때

- 사이트(`index.html#unit/<단원>`)는 `animations/<파일>?embed`를 iframe으로 넣습니다. 주소에 `embed`가 있으면 플레이어가 `<html>`에 `embed` 클래스를 붙여 머리말(제목·설명)과 아래 노트를 숨기고, 내용 높이를 `postMessage({type: "st-anim-height", h})`로 부모 페이지에 알려 iframe 높이를 맞춥니다.
- 단원에 영상이 있으면 단계 애니메이션 위에 `영상으로 보기` 블록이 먼저 나오고, 단원 상단 버튼·목차·단원 카드에도 `▶ 영상`이 표시됩니다.
- 따로 열었을 때는 머리말의 단원 칩(예: `2-10`)이 사이트의 그 단원 페이지(`../index.html#unit/2-10`)로 가는 링크가 됩니다.

렌더링은 헤드리스 브라우저로 단계마다 화면을 찍어 확인했습니다(밝은·어두운 테마, 폭 1280·390).
