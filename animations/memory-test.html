메모리 테스트와 불량 분석: PE가 하는 일

메모리 테스트는 수십억 개 셀이 규격 안의 전압·온도·속도에서 모두 제대로 동작하는지 정해진 패턴으로 확인해 불량을 고치거나 걸러내는 일이고, 불량 분석은 실패한 비트의 모양과 조건에서 출발해 전기적·물리적 분석으로 소자·공정의 원인을 찾아 되돌려 주는 일입니다. 건강검진(테스트)으로 이상이 있는 사람을 골라낸 뒤 혈액검사 → 영상 촬영 → 조직검사(불량 분석) 순서로 병명을 찾는 것과 같습니다.

    기억할 점

    • 불량 분석 도구: 테스터(ATE)·FBM(어떤 비트가 어떤 조건에서 실패하나), EMMI·OBIRCH·열화상(결함의 빛·저항·열 변화 위치), X선·SAT(패키지 내부)는 비파괴이고, 나노 프로빙(트랜지스터 하나의 I-V), 디프로세싱·FIB(층 벗기기·단면), SEM·TEM·EDX(모양·결정·성분)는 파괴 분석입니다.
    • 테스트 시간을 줄이는 방법: 여러 칩 동시 측정(멀티 사이트), 칩 안 자체 테스트 회로(BIST), 중복 항목 정리, 데이터로 불필요한 항목을 빼되 불량 유출이 늘지 않는지 검증.
    • HBM은 D램을 쌓은 뒤에는 고치거나 바꾸기 어려워, 쌓기 전에 좋은 다이만 고르는 KGD 테스트와 쌓은 뒤의 테스트가 모두 중요합니다(4-5). 웨이퍼 맵 불량 패턴을 자동으로 분류하는 머신러닝도 쓰입니다.

    원고 3-17을 움직이는 그림으로 옮겼습니다. 이어서 볼 단원: 2-10 D램 동작 심화, 3-11 EDS, 3-13 수율·결함, 4-5 HBM.
